# CyberOS

A lightweight, retro cyberpunk-themed desktop environment that runs entirely in your web browser. Built using just vanilla HTML, CSS, and JavaScript with zero external frameworks or dependencies.

## What's Inside

- **Window Management:** Open, drag, minimize, maximize, and close windows. Clicking an open window brings it to the top.
- **Taskbar & Start Menu:** Active apps show up as tabs on the bottom taskbar so you can minimize and restore them easily.
- **Terminal:** A built-in command prompt. You can launch apps, evaluate math, or switch themes directly with commands.
- **Calculator:** A quick on-screen arithmetic calculator.
- **Matrix Rain Visualizer:** Real-time animated green digital rain rendered on an HTML5 canvas.
- **Notepad:** A basic scratchpad that saves your text to your browser's local storage automatically.
- **File Explorer:** A mock file directory.
- **Theme Switcher:** Switch between three color palettes on the fly: Cyberpunk (cyan/pink), Matrix (green), and Synthwave (purple/neon).

## How to Run It

You don't need Node.js, npm, or any installation setup.

1. Download or clone this folder.
2. Make sure `index.html`, `styles.css`, and `script.js` are in the same directory.
3. Double-click `index.html` to open it in Chrome, Firefox, Edge, or any modern browser.

## Project Structure

## Terminal Commands

If you open the terminal app inside the OS, here are a few things you can type:

- `help` - List available commands.
- `open [app]` - Launch an app (calc, notepad, files, visualizer, system, themes).
- `calc [expression]` - Run a quick math calculation (e.g., `calc 45 * 12`).
- `theme [name]` - Switch theme (`cyberpunk`, `matrix`, or `synthwave`).
- `time` - Print the current UTC timestamp.
- `clear` - Clear the terminal output.
